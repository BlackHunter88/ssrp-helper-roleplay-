HELP & SUGGESTIONS

1. MULTI-ZONE SYSTEM

  • Gunakan tombol TOP LEFT, TOP RIGHT, dsb untuk memilih zona.
  • Setiap zona berdiri sendiri.

2. ZOOM & PAN (NEW!)

  • Gunakan tombol (+) dan (-) untuk Zoom.
  • Geser (Drag) gambar untuk melihat bagian tertutup.
  • Tombol FIT VIEW untuk reset posisi.

3. PER-IMAGE MEMORY

  • Setiap gambar menyimpan teksnya masing-masing.

4. TIPS

  • Gunakan [Says] dan [Shouts] untuk format otomatis.
