HELP & SUGGESTIONS

1. MULTI-ZONE SYSTEM

  • Gunakan tombol TOP LEFT, TOP RIGHT, dsb untuk memilih zona.
  • Setiap zona berdiri sendiri. Teks di Top Left tidak akan menimpa Bottom Right.
  • Kamu bisa mengisi 4 zona sekaligus dalam 1 gambar.

2. PER-IMAGE MEMORY (BARU!)

  • Setiap gambar menyimpan teksnya masing-masing.
  • Jika kamu ganti ke Gambar 2, editor akan bersih (atau sesuai isi Gambar 2).
  • Jika balik ke Gambar 1, editan kamu tidak hilang.

3. TIPS & TRICK

  • Gunakan [Says] dan [Shouts] untuk format otomatis.
  • Teks warna warni? Gunakan palet warna di atas editor.
  • Gunakan tombol IMGUR UPLOAD untuk mendapatkan link langsung.

4. SARAN GW

  • Untuk SIZE bisa dibuat di 27 dan SPACE bisa di 27 juga
  • dah itu aja sih, semua boleh di ubah sesuka kalin! ENJOY GUYS!!

5. BUG INFORMATION

  • Untuk fitur IMGUR UPLOAD Lagi bug ya Guyss tunggu aja kalo mau dipake!
